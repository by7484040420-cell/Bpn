BIPIN AI — GitHub Actions APK

1. Is poore folder ko GitHub repository ke ROOT me upload karo.
2. .github/workflows/build-apk.yml ko rehne do.
3. Actions > Build Bipin AI APK > Run workflow.
4. Green hone ke baad Artifacts me Bipin-AI-debug download karo.

Is project ko Render ki zarurat nahi hai. APK me WebView aur AI form-fill UI bundled hai.
Official portals internet se WebView me khulte hain.
OTP/CAPTCHA/payment/file upload automatic nahi hain.
